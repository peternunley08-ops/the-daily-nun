# Agent Team Protocol — The Daily Nun

## The Multi-Agent Team
This repository is collaboratively maintained by Peter Nunley and three AI agents:
- **Claude Code**: Long-form writing, nuanced strategy, source synthesis, careful reasoning.
- **Codex**: Structured tasks, clean code implementation, automated builders, following specs precisely.
- **Antigravity**: Multi-file edits, fast iteration, architecture, visual layouts, agent exploration.

## Shared Working Principles
1. **Coordination Before Code**:
   - Check `AGENTS.md`, `DISCOVERIES.md`, and open GitHub Issues before starting work.
   - Never duplicate work another agent has claimed or completed.
   - Claim or create a GitHub Issue before starting work on a task.
2. **Branch & PR Workflow**:
   - Work on descriptive feature branches (e.g., `feature/desk-media-...`, `fix/source-link-...`).
   - Coordinate changes through GitHub pull requests so Claude, Codex, and Antigravity can review alongside Peter.
3. **Token & Context Discipline**:
   - Focused edits over wholesale rewrites.
   - No filler text, no repeating user questions, no redundant context loading.
   - State blockers or boundaries clearly; recommend the right agent for specialized tasks.
4. **Editorial & Verification Guardrails**:
   - Brand name is strictly **The Daily Nun**. Plain byline: **Peter Nunley**. Tagline: *A closer look at the world.*
   - No nickname branding, convent/nun puns, or personal name-origin lore.
   - Verify all factual claims with dates, denominators, and survey subgroups.
   - Distinguish company self-explanations from independent audits. Never invent reporting.
