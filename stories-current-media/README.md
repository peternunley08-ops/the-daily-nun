# Six current-media Stories

Open index.html to preview and download individual images. Upload the PNGs in png/ as Instagram Stories. Each is 1080 × 1920.

Add a real Instagram link sticker using the corresponding source URL in COPY.md; source text printed on an image is not clickable. Keep the survey years and populations visible. The source notes distinguish platform statements, survey findings, and editorial interpretation.

Accessibility descriptions and complete text are in COPY.md and content.json. Use them wherever the publishing interface supports descriptions or provide a text equivalent when repurposing.

These are unpublished assets. No accounts or posting schedules have been created.
